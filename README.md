# ScutumAD · versiones publicadas

Aquí solo se publican las versiones terminadas de ScutumAD (paquetes `.zip` firmados), para que el actualizador de la extensión pueda descargarlas de forma anónima.

El código fuente se desarrolla en un repositorio aparte. Cada versión incluye las licencias de los componentes de terceros en `licenses/`.
